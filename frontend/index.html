Find your starting point before Module 1

A hands-on placement test — real commands in a simulated Linux and PowerShell terminal, not multiple choice. It sorts you into a Basic or Advanced starting track so week one moves at the right pace for you.

Start the test How it works

Sign in

Use the account your instructor set up for you. First login asks you to set a new password.

Answer 20 questions in a real terminal

10 Linux, then 10 PowerShell. Each question gives you a small simulated filesystem. Stuck? Hints are there if you need them — they just cost some credit. The terminal is scratch space, not the quiz.

Get your track

Takes about 20–30 minutes. Once it's done, it's final — no retries, nothing to prepare for in advance.

Before you start

This isn't a graded exam — it's here to help place you at the right pace, not to catch you out. See the help page for the full rules and a command reference.
