Help & test rules

Everything you need before you start — no surprises once the test begins.

The rules

  • The test is 30 questions — 15 about the Linux command line, then 15 about PowerShell. It takes most students 30–40 minutes.
  • Every question uses a small simulated terminal — run whatever commands you like, then type your answer in the box beside it.
  • Once you submit an answer, you can't go back and change it.
  • This isn't graded pass/fail on individual questions — it's a placement tool. There's no benefit to guessing, and no penalty for taking your time.
  • Once the test finishes, your result is final. There are no retries and no manual override.
  • Every command you type is logged, but nothing about how you got the answer affects your result — only the answer itself.

The simulated terminal

It's not a real shell — no real OS, container, or network underneath it, just a small filesystem and command interpreter for that one question. Nothing you do there can break anything or affect other students. Treat it as scratch space: explore, try commands, and once you've found the answer, type it into the answer box — not into the terminal.

Command reference — Linux

Everything the Linux terminal understands. Standard bash syntax — pipes (|) work between any of these.

CommandWhat it does
pwdPrint the current directory.
lsList files. Add -l for a long listing (permissions, size, date), -la to include . and ...
cat <file>Print a file's contents.
stat / wc / du <file>Report a file's size in bytes.
file <file>Report what kind of content a file holds.
echo "text"Print text back out — useful piped into other commands.
base64 -dDecode Base64 input. Use with a pipe, e.g. cat secret.b64 | base64 -d.
base64 -eEncode input to Base64.

Command reference — PowerShell

Everything the PowerShell terminal understands. Common aliases work too (ls/dir for Get-ChildItem, cat/type for Get-Content) — pipes (|) work between any of these.

CmdletWhat it does
Get-LocationPrint the current directory.
Get-ChildItemList files with details (name, size, date). Add -Name for names only.
Get-Item <file>Show one file's details, including its Length.
Get-Content <file>Print a file's contents.
Measure-Object -CharacterCount characters in piped input, e.g. Get-Content file.txt | Measure-Object -Character.
Get-FileHash <file>Compute a hash. Defaults to SHA256; add -Algorithm MD5 for MD5.
ConvertFrom-Base64StringDecode Base64 input, e.g. Get-Content secret.b64 | ConvertFrom-Base64String.
ConvertTo-Base64StringEncode input to Base64.
Write-Output "text"Print text back out — useful piped into other cmdlets.

Two of these — ConvertFrom-Base64String and ConvertTo-Base64String — are simplified for this sandbox; real PowerShell does Base64 conversion via [Convert] .NET methods rather than a dedicated cmdlet.

Trouble signing in?

Use the temporary password from your invite email on your first sign-in — you'll be asked to set a new one right away. If your account isn't working, contact your instructor rather than trying to sign up for a new one; accounts are set up in advance and there's no open self-registration.
